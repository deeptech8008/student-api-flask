# Student API using Flask

This project is a simple REST API built using Flask and SQLite.

## Features
- GET /students → View all students
- POST /add → Add new student
- GET /add-test → Add test data

## Technologies
- Python
- Flask
- SQLite

## How to Run
1. Install Flask
2. Run: python app.py
3. Open browser:
   http://127.0.0.1:5000/
